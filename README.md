# Caderno de Java

Curso interativo de Java do zero, em português: 10 módulos com lições, exercícios corrigidos na hora, desafios, revisões, projetos e uma colinha. O Java roda direto no navegador (por um interpretador próprio, sem servidor) e o app funciona offline depois de aberto uma vez.

## Instalar no celular

- **Android (Chrome):** menu ⋮ → **Instalar app**.
- **iPhone (Safari):** **Compartilhar** → **Adicionar à Tela de Início**.

## Atualizar

Envie os arquivos novos e mude `cadernojava-v1` para `cadernojava-v2` (e assim por diante) no `sw.js`, para os celulares baixarem a versão nova.

## Observação

O interpretador cobre o Java usado no curso (classes, herança, interfaces, Scanner, arrays, ArrayList, HashMap, exceções, printf etc.). Alguns recursos avançados, como enum, record e streams, não estão disponíveis aqui; para eles, use o JDK no computador.
